# kafka-for-developers-using-spring-boot

- A hands-on course repository demonstrating how to build production-grade event-driven applications with **Apache Kafka** and **Spring Boot 4**.

- The repo contains two Spring Boot microservices that form a complete producer→Kafka→consumer pipeline, backed by PostgreSQL, deployed to Kubernetes, and tested with EmbeddedKafka and Testcontainers.
