# 🧠 AGENTS.md vs SKILL.md — Explained Simply

## 🚀 Why This Matters

When working with AI coding agents, you need both **context** and **execution guidance**.

---

## ⚡ Quick Summary

| | AGENTS.md | SKILL.md |
|---|---|---|
| What is it? | Big picture guide | Task-specific guide |
| Analogy | Map | Recipe |
| Scope | Entire project | One task |
| When used? | Always | On demand |

---

## 🧠 Mental Model

- AGENTS.md = City Map 🗺️  
- SKILL.md = Cooking Recipe 🍳  

---

## 🌍 AGENTS.md

### Purpose
Understand the project and rules.

### Includes
- Project overview
- Architecture
- Coding conventions
- Build commands

### Key Idea
👉 Prevents mistakes but does NOT give step-by-step instructions

---

## 🛠️ SKILL.md

### Purpose
Execute a task correctly.

### Includes
- Exact annotations
- Code templates
- Step-by-step instructions
- Edge cases

### Key Idea
👉 Removes guesswork completely

---

## 🔄 Flow Diagram

```
User Request
     |
     v
AGENTS.md (Always Loaded)
     |
     v
Understand Project Context
     |
     +----------------------+
     |                      |
     v                      v
General Task          Specific Task
     |                      |
     v                      v
Execute Directly     Load SKILL.md
                           |
                           v
                 Follow Step-by-Step Guide
                           |
                           v
                    AI Agent Produces Code
```

---

## 🎯 Rule of Thumb

- AGENTS.md → Understand  
- SKILL.md → Execute  

---

## 🏁 Final Takeaway

👉 AGENTS.md gives direction  
👉 SKILL.md gives precision  

Together → Reliable AI-assisted development 🚀
